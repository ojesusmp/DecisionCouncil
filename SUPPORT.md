# Support — DecisionCouncil

For help with DecisionCouncil:

- **Bug reports / feature requests:** https://github.com/ojesusmp/DecisionCouncil/issues
- **Security issues:** see [SECURITY.md](./SECURITY.md). Do NOT open public issues.
- **Questions about usage:** open an issue with `question` label, or check `docs/EXAMPLES.md`.
- **Maintainer:** Orlando Molina (https://github.com/ojesusmp)

## What this project supports

- Protocol in `SKILL.md`
- Install paths in `docs/INSTALLATION.md`
- Verdict format in `docs/COUNCIL_PROTOCOL.md`
- Worked scenarios in `docs/EXAMPLES.md`

## What this project does NOT support

- Paid SLA support
- Use of the council to ratify pre-committed decisions
- Use to brainstorm or ideate new offers
- Custom forks delivered as upstream

## Response time

Best effort. Maintainer is solo.
